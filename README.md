# Камилла · маникюр в Альметьевске

Одностраничный сайт частного мастера маникюра. Статика без сборки: HTML, CSS и один JS-файл.

## Структура

```
index.html    — вся разметка страницы
styles.css    — оформление, адаптив, анимации
script.js     — меню, галерея, форма заявки
images/       — фотографии работ
```

## Запуск локально

Откройте `index.html` двойным кликом — сайт полностью работает из файла.

## Как править

| Что изменить | Где |
|---|---|
| Телефон, Telegram, Instagram | `index.html` (поиск по `79196226009`, `sweetie_78045`, `kamilla_nails_16`) и `script.js` (константы `PHONE_DIGITS`, `TELEGRAM`) |
| Цены | `index.html`, блок `<section class="prices">` и список услуг в форме |
| Тексты и вопросы FAQ | `index.html` |
| Цвета и шрифты | `styles.css`, переменные в `:root` |

### Добавить новую работу

1. Положите фото в `images/`.
2. Скопируйте любой блок `<figure class="gallery__item">` в `index.html` и замените имя файла, `data-src`, `alt` и подпись.

## Форма заявки

По кнопке «Отправить заявку» открывается WhatsApp мастера с уже готовым текстом; тот же текст копируется в буфер обмена — его можно вставить в Telegram.

Чтобы дублировать заявки на почту, создайте бесплатную форму на [formspree.io](https://formspree.io) и впишите её адрес в переменную `FORM_ENDPOINT` в `script.js`.

## Деплой
